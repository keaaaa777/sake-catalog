# 雫 SAKE SELECT 信頼性向上TODO

作成日: 2026-09-04  
目的: 画像改善と並行して、掲載情報の正確性・透明性・専門性を高める。

## 基本方針

- 公式情報で確認できない内容を推測で補完しない。
- 酒蔵公式サイト・公式商品ページ・公的資料を最優先の出典とする。
- 作業量よりも、出典・確認日・担当者を追跡できることを優先する。
- 全件を一度に公開せず、優先度の高い銘柄から確認・反映する。
- 画像は別進行中。画像の権利確認結果は、同じ出典管理方針に統合する。
